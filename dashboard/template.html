AIOps Sentinel

When AWS infrastructure raises an alarm, the system collects the logs, removes secrets, asks an AI for the root cause, saves the incident and alerts the team on Discord.

Simulated incidents. The incident simulator runs the project's real parsing, redaction, trimming and classification code on sample events. The AI text and the Discord alert are sample output. Nothing here is a live AWS reading; live alarms need the deployed stack (Modules 2 and 3).

Known limitations

  • The Groq key and webhook are Lambda environment variables, so they appear in Terraform state.
  • The daily token limit is a warning per Lambda container, not a hard cap.
  • Suggested actions are advice; nothing is fixed automatically.
